# Security

## Reporting a vulnerability

Please report it privately, not in a public issue. The mods published in this organisation are
built from [MaddisonM79/ryna_agent](https://github.com/MaddisonM79/ryna_agent), so that is where a
report goes: open its **Security** tab and choose **Report a vulnerability**
(<https://github.com/MaddisonM79/ryna_agent/security/advisories/new>). Only Maddison sees it.

Say what you found, in which mod, the version, and how to reproduce it. Please don't include
anyone's account names, character names or saved files.

## Supported versions

Only the latest release of each mod gets fixes.

## Checking a download

Every release here is published by ryna_agent's `release` workflow from a signed tag, and nothing
on a release is changed after it's published.
